# Pisum Whisper

Hotkey-driven, system-tray-style dictation tool. Hold a global hotkey to record speech, release to transcribe via AI, and the result is pasted at the cursor position.

## Status

Early scaffold — there is no runnable code yet. The repository currently holds the solution file,
an SDK pin, and tooling configuration; the first project has not been added. Everything about the
implementation (audio capture, transcription backend, tray/UI shell) is still open.

## Requirements

- .NET SDK `10.0.400` (pinned in `global.json`)
