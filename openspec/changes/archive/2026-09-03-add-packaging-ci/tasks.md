## Not in this change

- **Code signing and notarization.** Rejected deliberately, not deferred; see `proposal.md`'s *Non-goals* and design D6. Reversing it is a Developer ID purchase plus two `--sign` flags, and it would close `bootstrap-solution`'s task 1.4 for real.
- **A native Windows notification transport.** The AUMID makes it possible; building it is not this change. `spikes -- notify` and change 11's WinForms control run are what would settle it first.
- **Fixing `FileLoggingRotationTests`' latency bound.** Excluded by name in CI (design D9); the bound and its future belong to `file-logging`.
- **Version-bump automation.** A non-goal; tags are written by hand (design D8).
- **The ten open manual tasks the *Artifact status* table already lists.** CI does not close any of them, and this change does not claim to.
