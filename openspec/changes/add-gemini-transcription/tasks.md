Verify: unit test submits oversized bytes and asserts a `TranscriptionException` with that category and that the stub handler was never invoked.
- [x] 4.4 Implement `ExtractText`: surface a body-level `error.message` as `ErrorCategory.Transcription`; raise the same when there is no candidate, no part, no text, or text that is empty or whitespace. Verify: unit tests for each of the four empty shapes plus the error-object shape.
- [x] 4.5 Implement `IsRetryable(HttpResponseMessage, string body)` — true on 429 or 503, or on a body mentioning `overloaded` / `too many requests` / `rate limit` **only when `!response.IsSuccessStatusCode`**. - [x] 4.6 Implement the retry loop: 3 attempts total, `Task.Delay` of 1 s then 2 s between them, retrying on `IsRetryable` or on a transport `HttpRequestException`/`TaskCanceledException` that is not the caller's cancellation; honour `cancellationToken` in both the send and the delay. Verify: unit tests for 503-then-success (2 requests, no third), three 429s (3 requests, then raise), an immediate 400 (1 request), and cancellation during the backoff.
- [x] 4.7 Implement the failure-to-category mapping: 401/403 → `Authentication`; 429 or a quota-reporting response → `RateLimit`; transport failure or timeout → `Network`; everything else → `Transcription`. Truncate any body included in a message to 200 characters and only from an unsuccessful response. Verify: unit test per category asserting `TranscriptionException.Category`.
- [x] 4.8 Wire `TranscribeAsync` end to end: build the request from `EncodedAudio.Bytes` (base64) and `EncodedAudio.MimeType` with the caller's system prompt, `temperature 0.1`, `maxOutputTokens 8192`; run it through 4.6 and return the extracted text. Log the outcome, the category on failure and the transcript's character count on success — never the text, the body or the key. Verify: unit test asserts a successful round trip returns the transcript, and a log-capturing test (following `GlobalHotkeyLoggingTests`' shape) asserts no logged message contains the transcript text or the API key.
